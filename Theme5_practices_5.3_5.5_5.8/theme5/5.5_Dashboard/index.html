Дашборд військового аналітика

Особовий склад навчальних груп: категоріальні, структурні, часові, просторові та табличні дані

Клік по стовпчику графіка або маркеру на карті теж обирає групу

1. Чисельність за групами

Категоріальні дані → стовпчикова діаграма

2. Структура за військовими званнями

Частка від цілого → кільцева діаграма

3. Розподіл за роком народження

Часові дані → лінійний графік з накопиченням

4. Розташування груп

Просторові дані → карта (розмір кола = чисельність)

5. Особовий склад

Табличні дані → таблиця з сортуванням (клік по заголовку) і пошуком

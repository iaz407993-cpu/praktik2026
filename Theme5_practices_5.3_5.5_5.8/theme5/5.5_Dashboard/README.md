# Практична робота 5.5 — візуалізація різних типів даних

Дашборд на основі шаблону `Practice55/start` (HTML + CSS Flexbox + Chart.js + Leaflet), дані — `mock.js` (без змін).

| Блок | Тип даних | Візуалізація |
|---|---|---|
| KPI-картки | агреговані показники | 4 картки: склад, середній вік, офіцери, сержанти/капрали |
| 1 | категоріальні | стовпчикова діаграма з накопиченням: групи × звання |
| 2 | частка від цілого | кільцева діаграма за званнями (з % у підказці) |
| 3 | часові | лінійний графік за роком народження + накопичувальна крива |
| 4 | просторові | карта Leaflet, розмір кола — чисельність групи |
| 5 | табличні | таблиця з сортуванням і пошуком |

Взаємодія: фільтр «Група» (або клік по стовпчику / маркеру на карті) узгоджено оновлює KPI, діаграми, карту і таблицю. Під кожним графіком — коротка автоматична інтерпретація.

## Запуск
`main.js` підключено як ES-модуль, тому відкривати через локальний сервер:
```bash
python -m http.server 5500
# http://localhost:5500
```

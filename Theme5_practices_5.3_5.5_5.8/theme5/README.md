# Тема 5 — практичні завдання 5.3, 5.5, 5.8 (варіант 5)

| Завдання | Папка | Зміст |
|---|---|---|
| 5.3, варіант 5 | `5.3_Network_graph/` | Network Graph взаємодії підрозділів (J-структура, підпорядкування, інформаційні канали): центральність, точки зчленування, мости, стрес-тест відмов, сценарій дублювання каналів; статичний PNG + інтерактивний Plotly HTML |
| 5.5 | `5.5_Dashboard/` | Дашборд на шаблоні `Practice55/start`: категоріальні, структурні, часові, просторові й табличні дані (Chart.js + Leaflet), єдиний фільтр за групою |
| 5.8, варіант 5 | `5.8_Panorama-OVU/` | Міні-ІАС «Панорама-ОВУ»: PostgreSQL → FastAPI (sync) → Web; режими executive / analyst / demo, порівняння періодів, панорама зрізів |

Веб-сторінки відкривати через `python -m http.server` (ES-модулі та fetch не працюють з `file://`). Інструкції — у README кожної папки.

# Data card — `digits`

| Поле | Значення |
|---|---|
| Назва | Optical Recognition of Handwritten Digits (UCI ML Repository) |
| Автори | E. Alpaydin, C. Kaynak, 1998 |
| Доступ | вбудований у scikit-learn: `sklearn.datasets.load_digits()` — файли даних у репозиторій не копіюються |
| Ліцензія | CC BY 4.0 (UCI) |
| Обсяг | 1797 зображень, 10 класів (174–183 на клас) |
| Schema | `X`: 8×8, оригінальні значення 0–16 → у проекті поділено на 16 (float32, 0…1); `y`: int 0–9 |
| Labels | розмітка авторів датасету; цифри написали 43 особи, зображення нормалізовані за розміром і центровані |
| Обмеження | низька роздільність; немає ідентифікаторів авторів (split за авторами неможливий); дані «чистіші» за реальні скани |
| Чутливість | персональних, службових чи обмежених даних немає |

## Split
`splits.npz` — індекси `train` (1077), `val` (360), `test` (360), stratified, seed 42. Створюється `notebooks/01_data.ipynb`. Точних дублікатів зображень немає, перетинів між частинами немає.

## Що варто розуміти в цих даних

**Пропуски сховані за нулями.** `df.isnull().sum()` показує нуль пропусків,
але у 20 записах розміри `x`, `y` або `z` дорівнюють нулю. Діамант не може
мати нульову довжину — це пропущений вимір, записаний нулем:

```python
df[['x', 'y', 'z']] = df[['x', 'y', 'z']].replace(0, np.nan)
```

Ще в наборі є 146 повних дублікатів. Після очищення залишається 53 794 записи.

**Категорії впорядковані.** Огранка Fair → Ideal, колір J → D, чистота I1 → IF.
Кодувати їх треба з явним зазначенням порядку, інакше `cat.codes` присвоїть
коди за алфавітом і зіпсує сенс.

**Залежність ціни від ваги нелінійна** — на діаграмі розсіювання крива
загинається вгору. Саме тому дерево рішень удвічі точніше за лінійні моделі.

**Парадокс огранки.** Діаманти найкращої огранки Ideal мають найнижчу медіанну
ціну (1 813 $), а найгіршої Fair — одну з найвищих (3 282 $). Пояснення:
ідеальну огранку частіше роблять на дрібних каменях. Це гарний матеріал
для висновків — показує, що кореляція не означає причинність.

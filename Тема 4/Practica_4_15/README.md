## Запуск

1. Завантажте репозиторій і відкрийте цю папку у VS Code або Jupyter. Зберігайте ноутбуки та CSV разом.
2. Встановіть залежності: `python -m pip install -r requirements.txt`.
3. Відкрийте ноутбук свого варіанта та виберіть ядро Python із установленими залежностями.
4. Виконуйте клітинки послідовно через `Shift+Enter`.
5. Виконайте завдання й експерименти, зазначені в ноутбуці. Оформіть власний висновок і збережіть роботу.

Після встановлення залежностей можна працювати без мережі. Варіант 3 не потребує зовнішньої LLM.

## Результат роботи

Здайте ноутбук із результатами виконання, відповідями на запитання, власним висновком і щонайменше одним обмеженням методу. Для варіанта 3 кожне число у висновку має бути пов’язане з ID джерела. Критерії оцінювання наведено в ноутбуках; максимум — 10 балів.
